Technical Details

  • Documents: 8,150 FBI documents, 236,174 text chunks
  • OCR: AWS Textract + Surya for text extraction
  • Embeddings: nomic-embed-text via Ollama (768 dimensions)
  • Dimensionality Reduction: UMAP for 2D visualization
  • Network Analysis: NetworkX with Louvain community detection
  • GPU Rendering: Cosmograph for WebGL force-directed graphs
  • Visualization: Plotly.js, Cosmograph, custom D3.js

Resources

  • Dataset: HuggingFace - svetfm/epstein-fbi-files
