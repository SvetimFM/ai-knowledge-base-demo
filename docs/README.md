# HPC Documentation

**Documentation files are NOT included in this repository.**

This directory is excluded from git (see `.gitignore`) to keep the repository lightweight. Download documentation using the provided scripts.

## Download Scripts

### HPC Documentation (NVIDIA, AMD, GitHub Repos)
```bash
bash scripts/download-hpc-docs.sh
```

This comprehensive script downloads:
- **NVIDIA**: CUDA, NCCL, HPC SDK, GPUDirect (~20 PDFs)
- **AMD**: ROCm, RCCL, HIP, Instinct GPUs (~20 PDFs)
- **GitHub Repos**: ~30 benchmark and LLM training repos
  - HPC: STREAM, HPL, HPCG, NCCL tests, OSU benchmarks
  - LLM: llm.c, Megatron-LM, DeepSpeed, vLLM, Flash Attention
  - Config: Ansible Slurm, OpenMPI, CUDA samples
- **Community**: Best practices, tuning guides (~10 files)

### Presidio IT Solutions Documentation
```bash
bash scripts/download-presidio-docs.sh
```

Downloads 26 Presidio documents:
- Case studies (Q2, NHL, DraftKings, etc.)
- Cloud & AI solution briefs
- Technical blogs
- Partner documentation

## After Downloading

### Upload to S3
```bash
# For HPC docs
bash scripts/deploy-docs.sh

# For Presidio docs (already configured in script)
bash scripts/download-presidio-docs.sh  # Automatically places in correct location
```

### Trigger Knowledge Base Ingestion
```bash
bash scripts/sync-kb.sh
```

## File Requirements

### Supported Formats
- PDF (preferred for whitepapers/guides)
- Markdown (.md)
- Plain text (.txt)
- README files from GitHub repos

### Best Practices
- Keep individual files under 50MB
- Use descriptive filenames
- Organize by vendor/category
- Include source URLs in metadata

## Troubleshooting

### Download Script Fails
- Check internet connection
- Verify `wget` and `git` are installed
- Some PDFs may require registration (script will skip)
- Run script multiple times to retry failed downloads

### Missing pandoc
If HTML→Markdown conversion fails:
```bash
# Ubuntu/Debian
sudo apt-get install pandoc

# MacOS
brew install pandoc
```

### S3 Upload Issues
Ensure AWS CLI is configured:
```bash
aws configure --profile your-profile
export AWS_PROFILE=your-profile
```

## Knowledge Base Ingestion

Once uploaded to S3, trigger ingestion:

```bash
# Check ingestion status
bash scripts/sync-kb.sh

# Or manually via AWS CLI
aws bedrock-agent start-ingestion-job \
  --knowledge-base-id YOUR_KB_ID \
  --data-source-id YOUR_DATA_SOURCE_ID \
  --profile your-profile \
  --region us-east-1
```

Ingestion typically takes 5-15 minutes depending on document count and size.
