# Example Queries for HPC Knowledge Base

This file contains example queries you can use with Amazon Q Developer CLI
to test your HPC Knowledge Base deployment.

## Getting Started

1. Navigate to the project directory
2. Start Amazon Q Developer CLI: `q`
3. Trust the MCP server (first time only):
   /tools trust awslabsbedrock_kb_retrieval_mcp_server___QueryKnowledgeBases
4. Copy and paste any query below
